      Printing on both sides

      The G3000 series can’t turn paper over by itself, so Canon Print does it in two rounds: it prints all the fronts, shows you exactly how to put the pile back, then prints the backs. It always uses the same simple move: turn the pile over like a page in a book.

      • Long edge: read it like a book. Use this for most documents.
      • Short edge: flip it up like a notepad or wall calendar.
      • If the backs come out upside down or on the wrong sheets, run the two-sided test under More options. It fixes this for you.

      Tips

      • Load paper in the rear tray, print side facing up/towards you.
      • Draft + Black & white uses the least ink.
      • For photos, choose High quality and the matching photo paper under More options.
      • Pick Save as PDF file as the printer to check a layout without using paper.
